Φ Transport Engineering Lab

Make the assumptions visible. Test how propagation delays, high-priority traffic, resource limits and node outages affect three routing heuristics on comparable abstract geometries, while constraining every topology by the same maximum capacity-weighted wire cost.

Not a physical network prediction. An image-derived line is not an authenticated botanical vessel. Pixels-per-tick is an invented propagation scale, strict priority can starve normal traffic, and the cost cap is a geometric proxy rather than measured dollars or equipment. No real routing hardware or sap transport is modeled.

Independent packet classes

High-priority packets transmit first whenever a link is contested. Both classes share the same finite node queues, with FIFO order within each class. This is deliberate strict-priority behavior, not a promise of fairness to standard traffic.
