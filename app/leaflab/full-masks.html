Φ Cannabiverse · Reference annotation · v1.6

Φ Full-Reference Mask Lab

Trace complete leaf boundaries on an actual local photo, independently export one reference per masked reviewer, then compare two observers on the same original image before measuring the model against each. Multiple green regions and subtractive holes are supported.

Honesty boundary: The software assigns every pixel to leaf or non-leaf using your polygons, but cannot prove you traced everything correctly. Two observers can agree and both be wrong. Hash matching proves image file identity, not true botanical ground truth, independent human review, or unseen holdout status. Never import model prediction as a human reference.

1 · Define a whole-frame reference

Open an original leaf photograph. We hash the actual bytes, not its filename.

Polygon tool

Click 3+ vertices on the actual image. Close a polygon to add a region, or subtract a hole. You can create multiple regions before exporting. Unknown/uncertain structures should be handled explicitly in your study protocol.

No reference contours saved. File-by-file review is self-asserted, never automatically certified.

2 · Trace on the original photo

Green outlines add target leaf; orange outlines subtract background. A green translucent fill is your rasterized reference. After importing two reviewers, red/cyan highlights show disagreements.

Color seeds for baseline (only after two masks)

Pair review and baseline

An observer-agreement score is not a botanical truth score. Model evaluation requires two distinct reviewer references, the same image bytes and identical target definitions.

4 · Multi-photo plant-level integrity

A study can have multiple images per plant, but they are not independent biological replicates. Importing a batch into the cohort audit checks duplicate source/observer pairs, shared original-file identity, missing second reviewers, and conflicting development/holdout roles for the same declared Plant ID.
