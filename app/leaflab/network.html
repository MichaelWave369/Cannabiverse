Φ Botanical Network Atlas

Explore annotated 2D line networks as graphs: how much wiring they use, how direct their paths are, and which connections matter when one link disappears. Compare those calculations with conventional minimum-spanning-tree and star layouts using the same marked positions.

This is a graph experiment, not vascular physiology. Human-drawn image features are not verified xylem or phloem. Edge crossings do not connect automatically. Image-pixel distance cannot represent actual fluid conductance, engineering throughput or biological optimality. No real specimen data ships with the app.
