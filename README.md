# Cannabiverse

Cannabiverse is a governed, source-aware atlas of Cannabis phytochemistry.

This repository is being bootstrapped from the Cannabis Phytochemical Atlas369 research line. The first full implementation will land through a reviewed bootstrap pull request rather than treating an empty public repository like a scratchpad.

Core rule:

> **IDENTITY ≠ OCCURRENCE ≠ BIOSYNTHESIS ≠ BIOACTIVITY ≠ HUMAN EFFECT ≠ SAFETY**

The data model keeps compound identity, occurrence evidence, biosynthetic claims, biological activity, human-effect evidence, and safety evidence in separate lanes.
