# Reconciliation Policy

Cannabiverse is append-audited rather than revisionist.

## Historical source rule

When a historical review contains a numbering error, nomenclature conflict, probable artifact, or claim later challenged by newer evidence:

1. preserve the historical record;
2. add a curation issue;
3. state the resolution explicitly;
4. adjust current interpretation in its own evidence lane;
5. never erase the old receipt.

## New compounds

A new structure enters confirmed canon only when the evidence reaches the release's declared acceptance gate. Putative MS assignments remain provisional unless a stronger identity receipt supports promotion.

## Search targets

A hypothesized molecule that was searched for but not detected is not a discovered Cannabis constituent.

## Natural occurrence

First natural isolation of a previously synthesized/known structure is an **occurrence upgrade**, not necessarily discovery of a new molecular structure.

## Scope

Counts are always release-scoped. "145 confirmed Atlas records" is a statement about this reconciliation release, not a final universal count of Cannabis phytocannabinoids.
