# Roadmap

## v0.1.0 — Bootstrap
- governed graph dataset
- permanent Atlas IDs
- source receipts
- schemas
- deterministic integrity validator
- standalone Query Explorer

## v0.2 — Evidence & Source Engine
- source nodes as first-class graph entities
- claim-to-source edges
- replication and contradiction receipts
- primary-vs-review evidence queries
- source dependency analysis

## v0.3 — Wider phytochemical atlas
- terpenes and terpenoids
- flavonoids
- phenolics
- flavoalkaloids
- chlorins/pigments
- sterols/lipids and other metabolite families

## v0.4 — Research workbench
- saved governed queries
- graph diffs between literature snapshots
- source timelines
- contradiction explorer
- exportable research receipts

## v1.0
A stable, source-aware Cannabis phytochemistry knowledge graph with documented release and reconciliation policy.
